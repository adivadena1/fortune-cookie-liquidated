A single fortune cookie line for a crypto trader who has just been liquidated — one line, at most 20 words, written to sound like a real fortune and land as a joke on the loss: rueful and warm, never cruel. The program writes the fortune to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
